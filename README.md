# Portfolio & Blog Hub

A modern, responsive React-based portfolio and blog application built using **React + Vite**. This project combines a professional personal portfolio, reusable React components, and a dynamic blog UI into a single application.

## 📌 Project Overview

Portfolio & Blog Hub is designed to showcase personal information, education, technical skills, projects, and blog posts through a clean and interactive user interface. The application demonstrates modern React development practices including reusable components, routing, state management, dynamic rendering, and responsive design.
